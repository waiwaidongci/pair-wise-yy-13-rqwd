# hxyfront-62012 纺织染整小样管理 · 订单投产放行

源提示词编号：7

纺织染整实验室小样管理前端系统：记录面料成分、克重、染料配方、浴比、温度曲线、
保温时间、后整理方式、色差值和评审结果，并在小样台账之上提供**订单投产放行**。

## 业务规则

- 放行绑定**客户订单**与提交时的**当前工艺快照**（含配方版本、后整理、保温时间、工艺调整人）。
- 四项核验全部通过方可放行：
  - Lab 色差 **ΔE ≤ 0.8**
  - 小样后整理与订单要求**一致**
  - 保温时间**达标**（≥ 订单要求）
  - **复核人不同于工艺调整人**
- 已有有效放行时重复提交**沿用首次**放行，不重复出具（幂等）。
- **配方、后整理或保温时间**变更后原放行自动**失效**，须重新核验；失效旧版仍可在存档中查看。
- 选择订单时按 **有效放行 / 待重评 / 缺样品批次**（另有未放行）分组筛选。
- 评审评语仅作参考：评语通过但不满足放行规则时（如 ΔE 超标）不能排大货。

## 分层

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 规则 | `src/domain/` | 类型与放行判定规则（阈值、四项核验、订单状态、失效变更），不依赖页面 |
| 存档 | `src/archive/` | 演示台账数据、放行单写入/失效/留存、localStorage 持久化 |
| 页面 | `src/components/` + `App.tsx` | 订单选择、放行核验、工艺调整、旧版存档展示 |
